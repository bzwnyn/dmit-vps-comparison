## DMIT 是什么，值不值得买

简单说：2018 年开始跑 VPS 业务，美国纽约注册，华人背景，中文客服，支付宝能付。机房在洛杉矶、香港、东京（以及圣何塞）。

贵。不超售。线路质量在同价位里属于顶格。

这三句话基本就是 DMIT 的全部特点了。它不是什么都适合的万能选手，定位很窄——专门服务对线路有要求、愿意为"稳定"多付钱的用户。

用过的人通常会提到两件事：一是晚高峰没有明显掉速，二是 CN2 GIA 线路确实稳——这两点对国内用户来说是真实痛点，DMIT 答得比较好。

弱点也明显：热门套餐经常缺货，工单响应不算快（一般 24 小时内回复），价格对预算有限的用户不友好。

## 读懂 DMIT 套餐名的逻辑

DMIT 的套餐名是有规律的，拆开来看：

**机房代号 + 平台代号 + 线路系列 + 规格**

比如 `LAX.AN5.Pro.TINY`：
- `LAX` = 洛杉矶机房
- `AN5` = AMD EPYC 9005 第五代平台
- `Pro` = Premium 旗舰线路
- `TINY` = 最小配置

三个机房代号：`LAX`（洛杉矶）、`HKG`（香港）、`TYO`（东京）

三条线路：`Pro`/`Premium`、`EB`/`Eyeball`、`T1`/`Tier 1`

搞清楚这个，官网那些名字就不再神秘了。

## 三条线路有什么不同

这是选 DMIT 套餐最核心的问题。硬件差异不大（全系 AMD EPYC + KVM + 企业级 SSD），真正区别在网络：

**Premium（Pro 系列）**：旗舰线路。三网 CN2 GIA 双向优化——电信联通去程走 CN2 GIA，移动 CMI，三网回程全部 CN2 GIA。这是民用级别里对国内访问质量最高的线路方案之一。洛杉矶 Premium 实测到国内延迟约 155-165ms，丢包率 0.1% 以下；香港 Premium 到内地通常 20-50ms。贵，但稳。

**Eyeball（EB 系列）**：中间档。洛杉矶 Eyeball 回程走 CMIN2，电信联通去程走 CN2 / AS9929；香港 Eyeball 走三网 CMI。比 Premium 便宜，线路质量够用，联通移动用户体验很不错，电信用户稍弱一档。价格通常比 Premium 便宜 30-40%。

**Tier 1（T1 系列）**：国际线路，没有专门的大陆优化。接入了多个国际 Tier 1 运营商，适合不以国内用户为主的业务。胜在流量大、价格低，而且流量超出后不断线，自动降速继续跑。

简单版总结如下：

| 线路 | 大陆优化 | 适合场景 | 价格档位 |
|---|---|---|---|
| Premium | ✅ 三网 CN2 GIA 双向 | 建站面向国内、对延迟敏感 | 最贵 |
| Eyeball | ✅ CMIN2/CMI 回程 | 性价比选手，联通移动优先 | 中档 |
| Tier 1 | ❌ 国际线路 | 大流量、国际业务、预算有限 | 最便宜 |

## 几件容易踩坑的事

**关于库存**。DMIT 明确不超售，所以热门套餐真的会缺货，看到合适的不用拖。

**关于优惠码的有效期**。DMIT 的优惠码有时效，下单前在购物车页面的 "Apply Promo Code" 输入框粘贴进去，点 "Validate Code" 验证，看到折扣刷新了再付款。

**关于月付还是年付**。年付比月付便宜不少，而且 DMIT 的续费价格与首次相同，没有"首年优惠、续费涨价"的套路。新用户如果不确定，可以先月付测一到两个月，确认延迟达到预期再转年付。

**关于 IP 被墙**。Premium 和 Eyeball 系列 IP 被墙后可以申请换 IP，每 15 天免费换一次，2026 年初已开放部分系列的自助换 IP 功能，不用再等客服。

**关于退款**。购买 3 天内、流量使用不超 30GB 可以全额退款（扣支付网关手续费）；30 天内可按剩余服务时间比例退款。不确定合不合适的话，先小配置试水是个稳妥的做法。
